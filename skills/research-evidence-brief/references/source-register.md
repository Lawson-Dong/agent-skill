# Non-exhaustive source register

Use these as **starting portals**, not quality rankings or closed whitelists. Check current availability and dates on each execution.

| Function | Entry | Notes |
| --- | --- | --- |
| Preprint primary | https://arxiv.org/ | Verify initial submission, every reviewed version and all relevant appendices. |
| Submitted review process | https://openreview.net/ | Submission is not acceptance; verify visible venue track and status. |
| Peer-reviewed publication | Conference and journal proceedings | Prefer stable DOI, confirm workshop versus main conference. |
| Original interpretability | https://transformer-circuits.pub/ | Research notes and technical articles: tag empirical vs conjectural. |
| Alignment science blog | https://alignment.anthropic.com/ | Direct lab research communications, not necessarily independent evidence. |
| OpenAI alignment | https://alignment.openai.com/ | Verify posting and underlying paper dates. |
| DeepMind publications | https://deepmind.google/research/publications/ | Target original work and version. |
| Independent evaluators | https://metr.org/ | Distinguish evaluation proposals from measured results. |
| Alignment assessment group | https://evals.alignment.org/ | Proposal notes and assessor methodology. |
| Alignment Research Center | https://www.alignment.org/ | Theory and conceptual work can be valuable without experiments. |
| Technical community | https://www.alignmentforum.org/ | Authors, critique and original notes; evaluate item-by-item. |
| Model exploration tools | https://www.neuronpedia.org/ | Artifact/tool usability not proof of mechanism validity. |
| Reproduction and critique | Linked repos, replications and formal responses | Check independence in data, model, authors and evaluators. |
| Discovery-only | Newsletters, news, social aggregators | Follow through to original source before making core scientific claims. |

Example method/problem expansion groups:
- Representation geometry: participation ratio, covariance effective rank, anisotropy, scaling, linear separability, CKA, probes, concept erasure, readout basis, SAE faithfulness.
- Causal interpretability: activation patching, causal tracing, interventions, causal abstraction, circuit, mediation, negative controls, multi-model generalization.
- Alignment: scalable oversight, alignment auditing, monitorability, reward hacking, goal misgeneralization, deception, chain-of-thought faithfulness, policy compliance, prompt injection, benchmark validity.
