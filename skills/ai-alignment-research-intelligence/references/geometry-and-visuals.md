# Geometry, control and visuals

For sample-centered covariance C with eigenvalues lambda_i >= 0, define PR(C) = (sum lambda_i)^2 / sum lambda_i^2 for nonzero C. Record centering, sample count, feature dimension, pooling, normalization and covariance convention. PR is undefined for zero covariance. It is invariant to uniform rescaling, not general anisotropic transforms. Do not substitute entropy rank, sparsity, manifold dimension or quantum-state PR without matching definitions.

For binary class proportions p and 1-p:
C_total = p C_1 + (1-p) C_2 + p(1-p)(mu_1-mu_2)(mu_1-mu_2)^T.
A between-class rank-one term can lower pooled PR while within-class PR rises; this is a possible construction, not a universal mechanism. A scalar spectrum does not identify whether its leading direction controls classification.

For ResNets distinguish forward depth from training time, absolute block index from normalized depth, native avgpool from extra GAP, residual boundaries from individual operations, and pairwise cohort analysis of a pretrained classifier from training a binary model.
